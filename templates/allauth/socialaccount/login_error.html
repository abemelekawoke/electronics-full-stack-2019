Third-Party Login Failure

An error occurred while attempting to login via your third-party account.

This could be due to:

  • OAuth Credentials Not Configured - Social applications are not set up in the database
  • Google OAuth not configured - You need to set up Google OAuth credentials
  • Redirect URL mismatch - The OAuth callback URL is not registered in Google Cloud Console
  • Email permission not granted - Make sure to request email scope
  • App not published - Google OAuth app might be in testing mode

Quick Setup (Run in project root):

Windows:

setup_oauth.bat

Linux/Mac:

chmod +x setup_oauth.sh && ./setup_oauth.sh

Manual Setup:

python manage.py setup_social_apps --google-client-id "YOUR_CLIENT_ID" --google-secret "YOUR_SECRET"

Redirect URLs to register in Google Cloud Console:

http://localhost/api/auth/google/login/callback/
http://localhost/api/auth/google/login/callback/
