Third-Party Login Failure

An error occurred while attempting to login via your third-party account.

This could be due to:

  • Google OAuth not configured - You need to set up credentials in Django Admin
  • Redirect URL mismatch - The callback URL is not registered in Google Cloud Console
  • App not published - Google OAuth app might be in testing mode with no users

To fix this, configure Google OAuth in Django Admin:

  1. Go to Dashboard → Social Applications
  2. Add a new Social Application with Google as provider
  3. Enter your Client ID and Secret Key from Google Cloud Console
  4. Select localhost as the chosen site
