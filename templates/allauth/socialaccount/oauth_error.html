Third-Party Login Not Configured

OAuth Error: Social applications have not been configured in the database. You need to set up OAuth credentials to enable third-party login.

Quick Setup (Run in project root):

Windows:

setup_oauth.bat

Linux/Mac:

chmod +x setup_oauth.sh && ./setup_oauth.sh

Manual Setup:

python manage.py setup_social_apps --google-client-id "YOUR_CLIENT_ID" --google-secret "YOUR_SECRET"

To enable Google Login, you need to:

  1. Go to Google Cloud Console → APIs & Services → Credentials
  2. Create OAuth 2.0 Client ID credentials
  3. Enter your Google OAuth Client ID and Client Secret
  4. Add redirect URIs in authorized redirect URLs
Required Redirect URLs in Google Cloud Console: api/auth/google/login/callback/
/auth/facebook/login/callback/
